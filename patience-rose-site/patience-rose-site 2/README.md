# Patience Rose | Prodigy Collections

A mobile-first static launch storefront built from the supplied 14-page The Prodigy creative brief.

## Preview

Open `index.html` in a browser or serve the directory with `python -m http.server 8000`.

## What's included

- Story-first editorial homepage, campaign art drawn from the supplied PDF, collection filters and 10 browsable design previews.
- All product image zones are intentionally **illustrative placeholders**, not official garment photography.
- Accessible product details modal with safe disclosure that pricing, sizes and purchasing are not available yet.
- Responsive layout and reduced-motion consideration.

## Add photos later

Save product photos in `assets/products/` and replace each product card's `.product-visual` illustrative content with an `<img>` using the corresponding file path. Replace the modal preview in the same manner. Product names and story copy are already in `script.js`.

## Before production launch

Confirm brand identity/logo treatment, domain, size variants, product descriptions, prices, stock management, shipping, payment provider, contact information and checkout infrastructure. **This is a working frontend prototype, not a connected e-commerce backend.**
